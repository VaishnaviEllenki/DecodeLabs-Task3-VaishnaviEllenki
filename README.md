# 🔐 Password Generator

A simple and secure Password Generator built using Python. This application generates strong random passwords containing uppercase letters, lowercase letters, digits, and special characters to enhance account security.

## 🚀 Features

- Generate strong random passwords
- Custom password length support
- Includes:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (!@#$%^&*)
- Ensures password complexity
- Fast and lightweight command-line application

## 📖 How It Works

1. User enters the desired password length.
2. The program ensures the password contains:
   - At least one uppercase letter
   - At least one lowercase letter
   - At least one digit
   - At least one special character
3. Remaining characters are selected randomly.
4. Characters are shuffled for enhanced security.
5. A secure password is displayed.
